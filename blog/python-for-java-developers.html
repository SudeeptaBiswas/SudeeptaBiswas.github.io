Python for Java Developers

Started 2 November 2026 · In progress · Python 3, uv, httpx, pytest

Python is the language most AI tools are written in. These notes map each Python idea to the Java one I already know, so the new part is only what really differs.

These are my study notes from my AI Engineering Lab, not production experience. This post is in progress: a section is added as each topic is finished.

2. Syntax vs Java

  • Blocks are set by indentation and :. No ;, no ++.
  • None, True, and / or / not instead of null, true, &&.
  • Type hints are not enforced when the code runs. A checker such as pyright reads them.

3. Collections

list [..]   dict {k: v}   set {..} / set()   tuple (..)   len(x), x in y

nums = [0, 1, 2, 3, 4, 5]
nums[1:4]    # [1, 2, 3]  start included, end excluded
nums[-2:]    # [4, 5]     negative = from the end
squares = [n * n for n in nums if n % 2 == 0]   # a stream in one line
  • Use a set for x in items on big data: fast lookup. A list keeps order and duplicates.
  • Trap: def add(item, bucket=[]) shares one list between every call. Write bucket=None and create the list inside.

4. Classes and dataclasses

from dataclasses import dataclass, field

@dataclass
class Note:                      # a Java record / POJO
    title: str
    tags: list[str] = field(default_factory=list)   # "= []" is an error
  • self is this, written out. _x means "internal", by convention only.
  • @dataclass writes __init__, __repr__ and __eq__. Use it for data; a plain class for behaviour.
  • Duck typing: anything with a .run() method works. An abstract base class (ABC) is the explicit contract, like a Java interface, and fails early.

5. Modules, imports, exceptions

import x → search sys.path (script folder, then .venv) → run x top to bottom ONCE → cache
error → except blocks in order (child before parent) → else (no error) → finally (always)
  • Importing a module runs it, so a module should only define things at top level.
  • if __name__ == "__main__": runs only when the file is started directly.
  • No checked exceptions: nothing forces a catch, so docstrings list what a function raises.
  • raise AppError("...") from error keeps the original as the cause, like new AppException(msg, cause).
  • Catch at the edge, where you can do something useful.

6. Files, JSON, HTTP

from pathlib import Path
import json, httpx

notes = json.loads(Path("notes.json").read_text(encoding="utf-8"))   # text → dict

reply = httpx.post("http://127.0.0.1:11434/api/chat", json=body, timeout=60)
reply.raise_for_status()      # a 404 is NOT an exception until you ask
data = reply.json()
  • open(p, "w") wipes the file first; "a" appends. Open files inside with, like try-with-resources.
  • Catch httpx.TransportError, the parent of both connect errors.
  • On my Windows PC, localhost tried IPv6 first: 2.16 s per call, against 0.02 s with 127.0.0.1.

7. Testing with pytest

def test_search_sends_one_batched_call(monkeypatch):
    sent = []                                   # a spy, kept inside the test
    def fake_embed(texts):
        sent.append(texts)
        return [[1.0, 0.0]] * len(texts)
    monkeypatch.setattr(search_module, "embed", fake_embed)   # patch where it is looked up

    search_module.search("cat", ["a", "b"])

    assert len(sent) == 1
  • A test with no assert passes. Empty stubs call pytest.fail(...).
  • A call that should raise goes inside with pytest.raises(...).
  • Floats are not exact: compare with pytest.approx.
  • Fakes test my logic fast, with no model running. One test marked @pytest.mark.ollama proves the real thing; -m "not ollama" skips it.
  • To know a passing test really tests something, break the code on purpose: it must fail.

8. Check yourself

pyproject.toml, uv.lock and .venv in Java terms?

pom.xml, a Gradle lockfile, and a per-project ~/.m2.

7 / 2 vs 7 // 2?

3.5 vs 3.

What is wrong with def add(item, bucket=[])?

One list is shared by every call. Use bucket=None, then make a new list.

A list default in a dataclass?

field(default_factory=list).

Why can't you import a folder named 01_python_fundamentals?

It starts with a digit, so it is not a valid Python name.

Is a 404 an exception in httpx?

No. Check status_code or call raise_for_status().

Why keep a spy's list inside the test?

At module level it is shared by every test and never emptied, so results depend on test order.
