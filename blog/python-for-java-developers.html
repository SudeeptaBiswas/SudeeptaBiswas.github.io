Python for Java Developers

Started 2 November 2026 · In progress · Python 3.13, uv, httpx, pytest

Python is the language most AI tools are written in. These notes map each Python idea to the Java one I already know, so the new part is only what really differs. They come from phase 1 of my AI Engineering Lab, where every topic ends with exercises that must pass.

1. Setup: uv and venv

uv plays the role of Maven or Gradle: it installs Python and the packages, and runs files.

JavaPython with uv
Maven / Gradleuv
pom.xmlpyproject.toml
Gradle lockfileuv.lock: exact versions, commit it
~/.m2, shared by all projects.venv/, one per project, git-ignored
Java toolchain version.python-version (here 3.13)
<dependency>uv add httpx
test scopeuv add --dev pytest
mvn exec:javauv run python file.py
  • Each project gets its own isolated .venv, so packages never leak between projects.
  • uv run uses that .venv by itself. No "activate" step.
  • No main class: Python runs a file top to bottom. if __name__ == "__main__": marks the part that runs only when the file is started directly (more in section 5).

5. Modules and imports

  • Importing runs the file. import prompts runs prompts.py top to bottom once, then caches it; a second import returns the same object. Java runs nothing on import. So a module should only define things at the top level, not do things.
  • __name__ is "__main__" when the file is run, and the module's own name when it is imported. That is why checks at the bottom of a file run only when you start that file.
  • Where Python looks: first the folder of the file you ran, then .venv. A folder name must be a valid Python name to be imported: 01_python_fundamentals starts with a digit, so it can't be.

class OllamaError(Exception): ...            # my base error
class OllamaDownError(OllamaError): ...      # (Parent) = extends

try:
    reply = httpx.post(url, json=body, timeout=10.0)
except httpx.TransportError as error:        # parent of ConnectError and ConnectTimeout
    raise OllamaDownError(f"no Ollama at {url}") from error   # keeps the cause
else:
    print("no error")                        # runs only if try had no error
finally:
    print("always runs")
  • except blocks are tried in order, first match wins. Put the child before the parent.
  • else runs only when the try had no error. Java has no twin.
  • from error keeps the original as __cause__. Callers catch OllamaError and get every child.
  • No checked exceptions, so a docstring should list what a function raises.
  • Catch at the edge, where you can do something useful: the chat loop prints "Start Ollama: ollama serve", while the function deep inside raises. Don't catch what you can't fix.
  • Two styles: look first (if key in d:, the Java way) or just try (try: d[key] except KeyError:, the usual Python way). For dicts, d.get(key, default) does it in one call.

8. HTTP with httpx

import httpx

response = httpx.get("http://127.0.0.1:11434/api/version", timeout=10.0)
response.status_code          # 200
response.json()               # {"version": "0.40.14"}

response = httpx.post(url, json={"model": "qwen3:4b"}, timeout=10.0)
response.raise_for_status()   # a 404 is NOT an exception until you ask

with httpx.Client(base_url="http://127.0.0.1:11434", timeout=30.0) as client:
    client.get("/api/tags")   # many calls, one reused connection
  • json=... turns the dict into JSON and sets Content-Type for you.
  • Always give a timeout. A local model can be slow: a 500-token answer took about 70 s on my PC.
  • Nothing listening on a port gave ConnectTimeout, not ConnectError. Catch the parent httpx.TransportError to get both.
  • On Windows, localhost took 2.16 s per call and 127.0.0.1 0.02 s: localhost tries IPv6 first, fails, then waits. One set of exercises went from 25 s to 1.2 s with this change alone.

pytest rewrites a plain assert, so a failure shows both sides:

>       assert average([1.0, 2.0, 3.0]) == 2.5
E       assert 2.0 == 2.5
E        +  where 2.0 = average([1.0, 2.0, 3.0])
@pytest.mark.parametrize(("text", "expected_count"), [("the cat sat", 3), ("", 0)])
def test_word_count(text: str, expected_count: int) -> None:
    assert word_count(text) == expected_count       # each row is its own test

@pytest.fixture
def exam_scores() -> list[float]:                   # runs before each test that asks for it
    return [70.0, 80.0, 90.0]

def test_average_of_scores(exam_scores: list[float]) -> None:   # matched by the name
    assert average(exam_scores) == 80.0

def test_average_of_nothing_fails() -> None:
    with pytest.raises(ValueError, match="empty list"):
        average([])                                 # must raise INSIDE the with

def test_model_names_fake(monkeypatch: pytest.MonkeyPatch) -> None:
    def fake_get(url: str, timeout: float) -> httpx.Response:
        return httpx.Response(200, json={"models": [{"name": "qwen3:4b"}]},
                              request=httpx.Request("GET", url))   # needed by raise_for_status
    monkeypatch.setattr(httpx, "get", fake_get)     # for this test only
    assert model_names() == ["qwen3:4b"]

Why fakes:

Real modelFake
Model server offfailsstill runs
What it teststhe server + my codemy code only

  • So: fakes for my own logic, plus one test marked @pytest.mark.ollama that proves the real server agrees. Measured: 3 passed in 0.42 s with the server, 2 passed and 1 deselected in 0.09 s with -m "not ollama".
  • Patch the name where it is looked up. If search() calls embed from its own module, patch search_module.embed, not a copy you imported.
  • monkeypatch is itself a fixture that comes with pytest. So is capsys, which captures print() (Java: a fake System.out). monkeypatch.setattr("builtins.input", fake_input) types lines for a command-line app with no keyboard.
  • Lesson folders start with a digit, so they can't be imported as packages. pyproject.toml adds the folder under test to pytest's pythonpath instead.
  • A test with no assert passes. Empty stubs call pytest.fail("not written yet").
  • To know a passing test really tests something, break the code on purpose: it must fail.

10. Check yourself

pyproject.toml, uv.lock and .venv in Java terms?

pom.xml, a Gradle lockfile, and a per-project ~/.m2.

7 / 2 vs 7 // 2?

3.5 vs 3.

What does if items: test?

That the collection is not empty. 0, "", [], {} and None are false.

What is wrong with def add(item, bucket=[])?

One list is shared by every call. Use bucket=None, then make a new list.

What does @dataclass write for you?

__init__, __repr__ and __eq__.

What is __name__ when a file is run, and when it is imported?

"__main__" when run; the module's own name when imported.

raise OllamaDownError(...) from error keeps what?

The original error, as __cause__. Java: new X(msg, cause).

Is a 404 an exception in httpx?

No. Check status_code or call raise_for_status().

Why pytest.approx for 0.1 + 0.2?

Floats are not exact: (0.1 + 0.2) / 2 is 0.15000000000000002.

Why keep a spy's list inside the test?

A spy is a fake that records what it was called with. At module level it is shared by every test and never emptied, so results depend on test order.
