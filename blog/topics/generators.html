Generators: yield

The chatbot must print each piece of the answer the moment it arrives. A generator does that: a function with yield hands out values one at a time. Java view: an Iterator whose next() runs until the next value.

Made on demand

from collections.abc import Iterator

def count_up(limit: int) -> Iterator[int]:
    for number in range(1, limit + 1):
        print(f"  making {number}")
        yield number                         # pause here; the loop gets number

numbers = count_up(3)                        # nothing printed: the body has not started
print("called count_up(3)")
for number in numbers:
    print(f"  got {number}")

leftover = list(numbers)                     # one pass only, like a Java Iterator
print("second loop got:", leftover)

Output:

called count_up(3)
  making 1
  got 1
  making 2
  got 2
  making 3
  got 3
second loop got: []
  • Calling count_up(3) runs nothing. It returns a generator.
  • Each loop step runs the body up to the next yield and pauses there, so "making" and "got" take turns.
  • One pass only: a second loop gets nothing, as with a used Java Iterator.

The chatbot's case: stream lines to text

Ollama sends the answer as JSON lines (see reading a streamed reply). The generator turns them into text pieces; the loop prints each one at once and keeps it for the chat history.

import json
from collections.abc import Iterator

# Stream lines in the shape qwen3:1.7b sent them; the last one has content "".
STREAM_LINES = [
    '{"message":{"role":"assistant","content":"R"},"done":false}',
    '{"message":{"role":"assistant","content":"AG"},"done":false}',
    "",
    '{"message":{"role":"assistant","content":" helps"},"done":false}',
    '{"message":{"role":"assistant","content":""},"done":true,"done_reason":"stop"}',
]

def text_chunks(lines: list[str]) -> Iterator[str]:
    for line in lines:
        if not line.strip():                 # blank line: nothing to parse
            continue
        text = json.loads(line)["message"]["content"]
        if text:                             # the last line's "" is not a chunk
            yield text

parts = []
print("bot> ", end="")
for chunk in text_chunks(STREAM_LINES):
    print(chunk, end="", flush=True)         # show each piece at once
    parts.append(chunk)
print()
print("saved to memory:", repr("".join(parts)), "from", parts)

Output:

bot> RAG helps
saved to memory: 'RAG helps' from ['R', 'AG', ' helps']

The last line's empty content is not handed out as a piece: that was a bug in the earlier stream code, and the chatbot's tests now check it. Blank lines are skipped too.
