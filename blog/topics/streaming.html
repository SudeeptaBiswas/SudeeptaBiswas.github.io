Reading a streamed reply (NDJSON)

With "stream": True (Ollama's default) the reply is NDJSON, newline-delimited JSON: one small JSON object per line. Each line holds a few characters of the answer; the last line holds the stats.

Why stream

Measured with qwen3:1.7b on a PC with no GPU:

First words on screenWhole answer
streamed0.13–0.64 s2.0–3.2 s
not streamedwhen it is all doneabout the same

Same total time, but the user reads while the model writes.

BodyHandlers.ofLines()with httpx.stream(...) as r: + r.iter_lines()

The real code (needs Ollama)

import json

import httpx

body = {"model": "qwen3:1.7b", "stream": True, "think": False,
        "messages": [{"role": "user", "content": "Why do chat apps stream their answers?"}]}

with httpx.stream("POST", "http://localhost:11434/api/chat", json=body, timeout=120.0) as response:
    for line in response.iter_lines():       # one JSON object per line, as it arrives
        if not line:
            continue
        data = json.loads(line)
        print(data["message"]["content"], end="", flush=True)   # show now, no newline
        if data["done"]:                     # last line: empty content + the stats
            print()
            print(data["eval_count"], "tokens")

Try it without Ollama

The same loop over sample lines in the same shape:

import json

# Sample lines in the shape Ollama sends with "stream": True: one JSON object per line.
body = """{"message":{"role":"assistant","content":"RAG"},"done":false}
{"message":{"role":"assistant","content":" looks up"},"done":false}
{"message":{"role":"assistant","content":" documents first."},"done":false}
{"message":{"role":"assistant","content":""},"done":true,"done_reason":"stop","eval_count":5,"eval_duration":330000000}"""

pieces = []
for line in body.splitlines():               # real code: for line in response.iter_lines():
    if not line:
        continue
    data = json.loads(line)
    piece = data["message"]["content"]
    print(f"line -> {piece!r}")              # real code: print(piece, end="", flush=True)
    pieces.append(piece)
    if data["done"]:                         # last line: empty content + the stats
        stats = data

print("answer:", "".join(pieces))
seconds = stats["eval_duration"] / 1_000_000_000    # Ollama times are nanoseconds
print(f"done_reason {stats['done_reason']}, {stats['eval_count']} tokens, "
      f"{stats['eval_count'] / seconds:.1f} tokens/s")

Output:

line -> 'RAG'
line -> ' looks up'
line -> ' documents first.'
line -> ''
answer: RAG looks up documents first.
done_reason stop, 5 tokens, 15.2 tokens/s

The last line has done: true, empty content, and the same stats as a reply without streaming. Ollama's times are in nanoseconds.

Why .json() fails with "Extra data"

Forget "stream": False with a plain httpx.post, and the body is many JSON objects in one string. .json() reads the first one and stops at the second:

import json

body = """{"message":{"content":"R"},"done":false}
{"message":{"content":"AG"},"done":false}"""

try:
    json.loads(body)                         # what .json() does with the whole body
except json.JSONDecodeError as error:
    print("JSONDecodeError:", error)

print([json.loads(line)["message"]["content"] for line in body.splitlines()])   # one line at a time

Output:

JSONDecodeError: Extra data: line 2 column 1 (char 41)
['R', 'AG']
