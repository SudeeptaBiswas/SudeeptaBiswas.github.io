Organization
BJIT Limited — Client: Valmet Technologies Oy (Finland)
Role
Tech Lead (designation: Senior Software Engineer)
When
Nov 2015 – Sep 2017
Team
Team of 5
3widgets built from scratch
1000+products per structure (export/import)
5engineers led

Context

Valmet used ENOVIA and CATIA V5 to manage product designs. The team built tools to help engineers release, move and find product data.

My role

Led the team of 5: requirement analysis, design, WBS, client communication, code review and branching (merges, conflict resolution, tagging). Wrote design and technical documents.

What I built

  • 3 ENOVIA widgets from scratch with JavaScript, JPO, MQL, Java and TCL.
  • CATIA Client Tool (R2015x): designed and built a desktop app for continuous package release.
  • Product-structure export/import with Excel and CSV: export, import and update 1000+ products per structure.
  • Data migration and comparison tool.
  • OCR document search: see the OCR Document Search page.
