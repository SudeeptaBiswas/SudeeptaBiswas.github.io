OCR Document Search

Organization
BJIT Limited — Client: Valmet Technologies Oy (Finland)
Role
Developer (built it from scratch)
When
2015 – 2017

The problem

Many documents were scanned images inside PDFs. Normal search could not read them.

What I built

  • Text extraction from documents with Apache Tika.
  • OCR for scanned images and image PDFs with Tesseract.
  • Indexing and search with Apache Solr and SolrJ.

Results

Large document sets, including image-only PDFs, became searchable by their text.

Stack

  • Java
  • Apache Solr
  • SolrJ
  • Apache Tika
  • Tesseract OCR
