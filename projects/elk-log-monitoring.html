ELK Log Monitoring

Organization
BJIT Limited — Client: Valmet Technologies Oy (Finland)
Role
Owner, end to end
When
2015 – 2021
2–3 TBof logs
50+log formats parsed
10+Kibana dashboards
100visualizations

Context

Valmet's PLM platform needed one place to collect, search and alert on its logs.

What I did

  • Owned it end to end: first R&D, production release, then investigating issues after release.
  • Ran Elasticsearch, Logstash, Kibana and Filebeat on Docker (Red Hat).
  • Log parsing and ingestion for 50+ log formats, plus indexing.
  • Built 10+ Kibana dashboards with 100 visualizations.
  • Set up alerts in Kibana and Jenkins.
  • Protected the Kibana login with nginx authentication.
  • Used the logs to investigate and fix production issues.

Results

2–3 TB of logs searchable in one place, with dashboards and alerts, used to troubleshoot production issues.

Stack

  • Elasticsearch
  • Logstash
  • Kibana
  • Filebeat
  • Docker
  • nginx
